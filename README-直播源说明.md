## 二、成品：`tv-mini.m3u`（26 台，153 行）

从 154 个候选地址里实测筛出 123 个可用，按"URL 必须带明确频道代码 + 延迟最低"排序，
每台保留 1 个主源 + 1~2 个备用源（名字带 `·备`）。

- 央视 18 台：CCTV-1 ~ CCTV-17 + CCTV-5+
- 广东 8 台：广东卫视、广东珠江、广东体育、广东新闻、广东民生、深圳卫视、广州综合、广州新闻
- 主源实测延迟：国内 tsfile 节点 43~324ms（广东卫视 55ms、深圳卫视 324ms、CCTV-6/7/9/10/15 仅 43~68ms）；海外中转 700~1000ms

### 三步用起来

1. 在 GitHub 新建一个仓库（公开即可），把 `tv-mini.m3u` 传上去。
2. Apple TV 打开 **APTV → 配置 → 右上角 + → 订阅配置**，填入：
   ```
   https://cdn.jsdelivr.net/gh/<你的用户名>/<仓库名>@main/tv-mini.m3u
   ```
   （jsDelivr 有缓存，改文件后链接加 `?v=2` 之类可强制刷新）
3. 回首页"更新订阅"；然后进 **设置 → 关闭"延迟检测"**，这一步对老 HD 的流畅度影响最大。

> 不想建仓库也可以：把 m3u 放在家里任何一台常开的电脑/NAS 上，用 `python -m http.server 8000` 起个静态服务，APTV 填 `http://192.168.50.x:8000/tv-mini.m3u`，走内网更快。

## 三、必须知道的几件事

1. **这些源会失效。** 公开中转源寿命通常几天到几周，`38.75.136.137` 那条带 `auth=test20251009` 的令牌也可能哪天失效。失效了就切 `·备` 源，或让我重跑一次筛选脚本。
2. **广州台（tencentplay.gztv.com）是官方 CDN，但链接带腾讯云防盗链签名（txSecret/txTime），会过期**，一般几天。过期后从 cs3306 的最新列表里重新取。
3. **别挂 EPG。** fanmingming 的 `e.xml` 有 9.9MB，Apple TV HD 拉一次就能卡住，APTV 里不要填节目单地址。
4. **合规提示**：这些多为第三方中转或运营商源外泄，稳定和合规都没有保证，仅供家庭自用，不要二次分发。
5. **老机器的锅一半在硬件**：Apple TV HD 停更在 tvOS 26，A8 + 2GB，配合"1080p SDR + 关闭匹配动态范围/帧率 + 关闭自动更新 + 减少动态效果"能再顺一截。
